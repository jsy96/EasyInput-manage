# EasyInput Studio

EasyInput Studio 是 EasyInput V2.0 开发板的浏览器 PWA。网页和开发板共用一条语音与文字时间线，不区分电脑数量。开发板用 S5 录音发送，用 S6 开始或结束与小智的实时语音对话，用 S7 持续说话并将小智识别的文字写入网页聊天记录。

- 线上网页：https://studio.leige.online
- 语音服务：`wss://easy.leige.online`
- 目录约定：[AGENTS.md](AGENTS.md)
- 使用说明：[docs/VOICE_CHAT.md](docs/VOICE_CHAT.md)
- 协议：[docs/PROTOCOL.md](docs/PROTOCOL.md)

## 当前功能

- 网页与开发板录音统一按时间排序，最新一条显示在最上方。
- 网页只发送语音；每条录音最长 20 秒。
- S1 直接播放前一条历史语音，连续短按继续回听更早的信息，包括已读语音；到最早一条后不循环。长按 3 秒进入批量已读确认。
- S2 播放第一条未读语音，并重设 S1 回听起点；播放中按 S1 直接切到前一条，按 S2 从第一条未读开头播放，其他键停止。
- S3 设置每日闹钟，长按 S3 取消。
- S4 设置倒计时，运行中每秒短滴答、每分钟长滴答并播报剩余分钟。
- S5 短按开始录音，再短按结束并发送；长按 3 秒取消本次未发送录音。每条最长 20 秒，满时暂存并等待短按 S5 发送；发送失败自动重试，成功后语音提示。S5 无双击功能。
- S6 短按开始与小智实时语音对话，再短按立即结束收音和播放并关闭会话。小智回答时暂停收音，回答播完后自动继续听，可连续多轮交谈；旋钮可调音量。需开发板 Wi-Fi 联网并完成小智官方平台绑定。对话不写入网页时间线，与普通录音和网页实时监听互斥。
- 已移除记账输入及 S6 双击汇总入口；已有记账记录、待同步记录和设备页 CSV 导出保留。
- 网页“打开实时监听 / 关闭实时监听”直接控制板载采集，使用 20 ms PCM16 流，实时内容不写入历史；S7/S8 不控制这个开关。
- S7 短按开始持续语音转文字，小智识别结果逐条写入网页聊天记录，不播放小智回答；再短按立即停止收音，发送尾帧并最多等待 20 秒尾句。至少识别到一条且本轮全部文字得到一个已打开聊天页的显示回执，才播报“成功”；识别为空、出错或终止后等待网页回执超过 12 秒播报“失败”。网页需打开“语音”页；S7 与 S5 录音、S6 对话和网页实时监听互斥。
- S8 停用，移除 S7/S8 测量编辑、双击查询及旋钮测量编辑入口。已有血压血糖记录、待同步记录和设备页 CSV 导出保留。S5/S6/S7 短按在松手时执行，不等待双击窗口；旋钮继续调节闹钟、倒计时和音量。
- 云端最多保留 5000 条语音及转写文字消息，语音每条最长 20 秒。网页首屏加载最新 50 条，可继续加载更早历史；全部语音按每包最多 100 条分批下载 ZIP，也可从早到晚连续播放并随时停止。
- 网页只保留“语音”和“设备”两页。设备页负责在线状态、Wi-Fi/语音服务配置和固件升级。

完整按键和灯效约定见 [VOICE_CHAT.md](docs/VOICE_CHAT.md)。

## 本地运行

```sh
npm install
npm run dev
```

打开 `http://127.0.0.1:5173`。生产构建：

```sh
npm run build
```

网页构建产物写入 `dist/`。USB Serial、Web Bluetooth 和 PWA 安装需要 HTTPS 或 localhost，并使用当前版本的桌面 Chrome / Edge。

## 网页与云端检查

```sh
npm run typecheck
npm test
cd cloudflare
npm run typecheck
```

## 固件构建

开发板目标为 ESP32-S3，当前工程使用 ESP-IDF 5.5.5：

```sh
cd firmware/easyinput-monitor
idf.py build
python3 ../../scripts/export-firmware.py --version 0.4.19
```

2026-10-29 固件 0.4.19 已导出至 `release/firmware/0.4.19-v2-monitor/` 并烧录至身份匹配的目标 ESP32-S3，历史固件包保留。本次修复 S7 失败后被旧待发文字阻塞的问题，网页保持 0.4.7，网页及云端网关均未重新部署。本轮实际执行的 14 个测试文件、127 项测试、类型检查和网页构建通过；ESP-IDF 5.5.5 最终构建通过，应用镜像为 2,857,152 字节，应用分区剩余约 31%。烧录命令正常结束且三个镜像哈希校验通过，仅写入 bootloader、分区表和应用，保留 NVS 与录音 outbox。烧录后核验确认正常应用模式，串口记录应用版本 0.4.19 和固件正常启动，未发现 panic、栈异常或 brownout 签名。启动核验不代表 S7 端到端语音功能已经验证。

此前 2026-10-29 已配套发布网页 0.4.7、云端网关及固件 0.4.18 的 S7 转写功能，线上首页、应用脚本、样式及 Service Worker 与该次本地构建一致。该次 127 项自动化测试、类型检查、网页及 ESP-IDF 5.5.5 固件构建通过；固件 0.4.18 已烧录至目标 ESP32-S3，保留 NVS 和录音 outbox，串口确认应用版本、正常启动且启动日志未见 panic。该次固件包位于 `release/firmware/0.4.18-v2-monitor/`。这些结果不代表本次修复或 S7 端到端实测已经通过。`build/`、`release/`、`node_modules/`、生成的 `sdkconfig` 和 `managed_components/` 不提交 Git。

此前同日发布的网页 0.4.6 和固件 0.4.17 修复了 S6 小智对话的编解码栈不足及音频锁竞争问题；该版本已烧录并完成正常启动检查。此前的 S6 对话实测不代表本次 S7 功能已完成实板验收。

中文提示音由 [scripts/build-voice-prompts.py](scripts/build-voice-prompts.py) 使用 `edge-tts-chinese` 的云健男声生成，再转换为 8 kHz 单声道 μ-law 并打包为 `firmware/easyinput-monitor/main/assets/prompts.bin`。

## 烧录

在“设备 → 固件升级”中选择包含 `firmware.json`、bootloader、分区表和应用镜像的完整目录。网页会校验清单、文件大小和 SHA-256，识别到 ESP32-S3 后要求再次确认才写入。

自动进入下载模式失败时，保持开发板开机，短按并松开一次 BOOT，再重试并选择 ESP32 下载端口。板上没有独立 RESET/EN 键；更新完成后关机再开机恢复正常运行。

## 尚未完成或需要真机验收

- 所有红色慢闪状态统一为亮 0.5 秒、熄灭 2 秒；五颗 WS2812 点亮亮度为 1%。
- 固件编译和自动化测试不能替代板载麦克风、扬声器、GPIO8 共享电源、灯序、按键方向和声音水平/音质的实板验证。
- 实时麦克风需要开发板通过 Wi-Fi 直连云服务；蓝牙网关继续承载历史语音和状态。网络中断会停止实时采集。
- 此前固件 0.4.17 的小智对话已由实板日志确认连续上传、两次回答播放、回答后恢复收音及 S6 结束清理，用户试听确认两轮交谈和 S6 结束正常；首次绑定、连接中或回答中取消、断网后的退出提示仍需专项验证。当前采用轮流说话，回答播放期间暂停收音。
- S7 失败后，旧文字保留 FIFO 后台补传但不再阻塞新一轮（完全满队列除外）；成功仅按新一轮实际开始后的识别与显示回执计数，旧 ACK 不计入本轮。仍需实板验证失败后重试、旧新文字混合补传、连续识别和成功/失败播报。失败轮后来送达不会补播成功；只有持久化队首有断电保留保证，后续 RAM 队列和本轮音频不提供完整断电恢复。
- 用户报告的“第一次失败”触发原因尚未实机复现；本次队列重试修复和软件检查不代替 S7 端到端验收。
