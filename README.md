# EasyInput Studio

EasyInput Studio 是 EasyInput V2.0 开发板的浏览器 PWA。网页和开发板共用一条语音与文字时间线，不区分电脑数量。开发板用 S5 录音发送，用 S6 开始或结束与小智的实时语音对话，用 S7 持续说话并将小智识别的文字写入网页聊天记录，用 S8 开始／停止正计时并播报总时长。

- 线上网页：https://studio.leige.online
- 语音服务：`wss://easy.leige.online`
- 目录约定：[AGENTS.md](AGENTS.md)
- 使用说明：[docs/VOICE_CHAT.md](docs/VOICE_CHAT.md)
- 协议：[docs/PROTOCOL.md](docs/PROTOCOL.md)

> 当前源码包含 S5 持续上传、网页分割、S5/S6/S7 任意键停止与自动结束，已配套发布固件 0.4.23／网页 0.4.10 和云端网关；目标板已烧录并确认新版本正常启动。

## 当前功能

- 网页与开发板录音统一按时间排序，最新一条显示在最上方。
- 网页只发送语音；每条录音最长 20 秒。
- S1 直接播放前一条历史语音，连续短按继续回听更早的信息，包括已读语音；到最早一条后不循环。长按 S1 3 秒后松开，再长按 S2 3 秒将全部未读标记为已读，保留历史和音频。
- S2 播放第一条未读语音，并重设 S1 回听起点；播放中按 S1 直接切到前一条，按 S2 从第一条未读开头播放。S3/S4/旋钮按压停止播放，S5/S6/S7 可直接切换至对应功能；S8 独立计时，不停止播放。
- S3 设置每日闹钟，旋钮每格 30 分钟（00:00～23:30），数字播完后静置 3 秒保存；长按 S3 1.2 秒取消。北京时间 UTC+8，设置跨重启保存，每次开机需有效网络校时。到点后灯 2 慢闪 1 分钟，播报提示并播放一次约 10 秒短旋律；音频忙时延后。
- S4 设置倒计时，默认 30 分钟，旋钮每格 1 分钟（1～60 分钟），数字播完静置 3 秒开始；运行中按 S1～S7 或旋钮取消，S8 独立计时。每秒短滴答、每分钟播报剩余分钟。
- S5 短按开始持续录音并上传，按任意键停止，尾音传完且云端保存后网页才显示留言。移除 20 秒自动停止，默认一条录音对应一条留言；网页可手动分割。长按也按停止保存处理，不再取消录音。需要 Wi-Fi 直连，网页可关闭；S5 无双击功能。
- S6 短按开始与小智实时语音对话，按任意键立即结束收音和播放并关闭会话。小智回答时暂停收音，回答播完后自动继续听，可连续多轮交谈；旋钮可调音量。需开发板 Wi-Fi 联网并完成小智官方平台绑定。对话不写入网页时间线，与普通录音和网页实时监听互斥。
- 已移除记账输入及 S6 双击汇总入口；已有记账记录、待同步记录和设备页 CSV 导出保留。
- 网页“打开实时监听 / 关闭实时监听”直接控制板载采集，使用 20 ms PCM16 流，实时内容不写入历史；S7/S8 不控制这个开关。
- S7 短按开始持续语音转文字，小智识别结果逐条写入网页聊天记录，不播放小智回答；按任意键立即停止收音，发送尾帧并最多等待 20 秒尾句。至少识别到一条且本轮全部文字得到一个已打开聊天页的显示回执，才播报“成功”；识别为空、出错或终止后等待网页回执超过 12 秒播报“失败”。网页需打开“语音”页；S7 与 S5 录音、S6 对话和网页实时监听互斥。
- S8 短按开始正计时，再短按停止并播报总时长，下一次从零开始；与倒计时独立，断网可用，重启归零。音频忙时按实际停止时刻记数，空闲后播报，最多排队 8 次结果。S7/S8 旧测量编辑、双击查询及旋钮测量编辑仍停用，已有记录、补传和 CSV 导出保留。S5/S6/S7 在松手时开始，按下任意键即停止；S8 在没有板端语音会话时松手切换计时。不等待双击窗口。
- 云端最多保留 5000 条语音及转写文字消息；新 S5 录音不受 20 秒限制，网页自身录音仍最长 20 秒。网页首屏加载最新 50 条，可继续加载更早历史；全部语音按每包最多 100 条或约 64 MiB 分批下载 ZIP（更大的单条语音独立一包），也可从早到晚连续播放并随时停止。
- 网页只保留“语音”和“设备”两页。设备页负责在线状态、Wi-Fi/语音服务配置和固件升级。

## 操作时先看这些

- S5 录音、S6 对话、S7 转写、网页实时监听互斥。S5/S6/S7 期间按 S1～S8 或旋钮按键优先停止语音，本次按键不执行原功能，松手不补执行；旋钮旋转仍调音量；实时监听需在网页关闭。
- S5/S6/S7 连续 60 秒未检测到说话或单次达到 60 分钟时自动结束；S6 只在等用户说话时计静音，思考／播放期间不计，重新收音后给满 60 秒，总时长仍继续。手动或自动结束均保留 S5 尾音上传、S7 尾句和显示回执处理。静音基于现有音量检测，嘈杂环境可能延后触发，总时长上限仍生效。
- S6 回答期间暂停收音，等回答播完再说。S7 需保持网页“语音”页打开；云端保存不等于网页已显示，失败后文字仍可能补传。
- S5 采用固定缓冲和稳定编号重试，连续 30 秒没有云端进展会停止并提示失败；云端约 90 秒未收到新数据后保存已接收部分，标为“录音传输中断”。新录音不写入离线 Flash，历史 8 槽 outbox 仍保留并补传。开始提示或云端连接阶段按任意键会取消开始。
- 网页“开发板已读”可能来自完整播放或手动全部已读；网页播放不会改变开发板未读状态。

## 五灯速查（固件 0.4.22 起）

| 灯 | 含义 |
| --- | --- |
| 灯 1 | 接收新留言或下载语音时慢闪；有未读语音常亮；其余熄灭 |
| 灯 2 | 闹钟到点慢闪 1 分钟；正／倒计时运行每秒闪一次；仅设置闹钟时常亮；其余熄灭，按此顺序优先 |
| 灯 3 | S5 录音／S6 对话／S7 转写常亮；有待发送录音或文字慢闪；其余熄灭 |
| 灯 4 | 网页实时监听实际采集中慢闪；其余熄灭 |
| 灯 5 | 正在连接／重试连接 Wi-Fi 时慢闪；Wi-Fi 连接正常常亮；未连接 Wi-Fi 时熄灭 |

全部红灯亮度为 1%。慢闪为亮 0.5 秒、灭 1.5 秒；每秒闪一次为亮灭各 0.5 秒。完整步骤、优先级、配网与限制见 [VOICE_CHAT.md](docs/VOICE_CHAT.md)。

## 本地运行

```sh
npm install
npm run dev
```

打开 `http://127.0.0.1:5173`。生产构建：

```sh
npm run build
```

网页构建产物写入 `dist/`。USB Serial、Web Bluetooth 和 PWA 安装需要 HTTPS 或 localhost，并使用当前版本的桌面 Chrome / Edge。


## 固件构建

开发板目标为 ESP32-S3，当前工程使用 ESP-IDF 5.5.5：

```sh
cd firmware/easyinput-monitor
idf.py build
```

## 烧录

在“设备 → 固件升级”中选择包含 `firmware.json`、bootloader、分区表和应用镜像的完整目录。网页会校验清单、文件大小和 SHA-256，识别到 ESP32-S3 后要求再次确认才写入。

自动进入下载模式失败时，保持开发板开机，短按并松开一次 BOOT，再重试并选择 ESP32 下载端口。板上没有独立 RESET/EN 键；更新完成后关机再开机恢复正常运行。
