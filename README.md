# EasyInput Studio

EasyInput Studio 是 EasyInput V2.0 开发板的浏览器 PWA。网页和开发板共用一条语音与转写文字时间线，不区分电脑数量。网页录制语音，开发板可双击 S5 将说话转成文字发送。

- 线上网页：https://studio.leige.online
- 语音服务：`wss://easy.leige.online`
- 目录约定：[AGENTS.md](AGENTS.md)
- 使用说明：[docs/VOICE_CHAT.md](docs/VOICE_CHAT.md)
- 协议：[docs/PROTOCOL.md](docs/PROTOCOL.md)

## 当前功能

- 网页与开发板录音统一按时间排序，最新一条显示在最上方。
- 网页只发送语音；每条录音最长 20 秒。
- S1 直接播放前一条历史语音，连续短按继续回听更早的信息，包括已读语音；到最早一条后不循环。长按 3 秒进入批量已读确认。
- S2 播放第一条未读语音，并重设 S1 回听起点；播放中按 S1 直接切到前一条，按 S2 从第一条未读开头播放，其他键停止。
- S3 设置每日闹钟，长按 S3 取消。
- S4 设置倒计时，运行中每秒短滴答、每分钟长滴答并播报剩余分钟。
- S5 短按开始录音，再短按结束并发送；长按 3 秒取消本次未发送录音或转写。双击启动语音转文字，说完静音约 1.5 秒后自动转写并发送文字，最长录音 20 秒；需开发板 Wi-Fi 联网并完成小智官方平台绑定。满 20 秒后等待短按 S5 发送；发送失败自动重试，成功后语音提示。
- S6 记账：每笔从 0 输入，金额为 1～999 人民币整数元；先输入百十位，短按旋钮进入个位，再短按保存，例如 27 → 短按 → 3 → 短按保存 273 元。长按旋钮 3 秒取消，联网后同步云端，设备页可下载记账 CSV；离线最多暂存 64 笔，满时拒绝新记录。双击 S6 播报最近一笔，以及北京时间今天、昨天、前天的总金额；日期不明或汇总尚未补齐时明确提示。
- 网页“打开实时监听 / 关闭实时监听”直接控制板载采集，使用 20 ms PCM16 流，实时内容不写入历史；S7/S8 不控制采集。
- S7 循环记录妈妈高压、妈妈低压、爸爸高压、爸爸低压；S8 循环记录爸爸血糖、妈妈血糖。单击进入编辑并播报当前调整值，血压每格 ±10、血糖每格 ±1；第一次短按旋钮进入精调（±1 / ±0.1），第二次短按保存，长按旋钮 3 秒取消。最近值与每次成功保存的历史先保存在板端，断电保留；联网后自动补传，设备页可下载全部已同步历史 CSV。离线最多暂存 64 条，满时提示保存失败，不覆盖旧记录。双击 S7 播报四项最近血压，双击 S8 播报两人的最近血糖；查询不切换人物、不新增记录。
- S5～S8 双击以第一次松开到第二次按下不超过 400 毫秒判定；单击等待窗口结束后执行。
- 云端最多保留 5000 条语音及转写文字消息，语音每条最长 20 秒。网页首屏加载最新 50 条，可继续加载更早历史；全部语音按每包最多 100 条分批下载 ZIP，也可从早到晚连续播放并随时停止。
- 网页只保留“语音”和“设备”两页。设备页负责在线状态、Wi-Fi/语音服务配置和固件升级。

完整按键和灯效约定见 [VOICE_CHAT.md](docs/VOICE_CHAT.md)。

## 本地运行

```sh
npm install
npm run dev
```

打开 `http://127.0.0.1:5173`。生产构建：

```sh
npm run build
```

网页构建产物写入 `dist/`。USB Serial、Web Bluetooth 和 PWA 安装需要 HTTPS 或 localhost，并使用当前版本的桌面 Chrome / Edge。

## 网页与云端检查

```sh
npm run typecheck

npm run typecheck
```

## 固件构建

开发板目标为 ESP32-S3，当前工程使用 ESP-IDF 5.5.5：

```sh
cd firmware/easyinput-monitor
idf.py build
python3 ../../scripts/export-firmware.py --version 0.4.15
```

固件包写入 `release/firmware/0.4.15-v2-monitor/`。2026-10-29 已部署网页 0.4.5 和配套云端网关，固件 0.4.15 已烧录并通过应用启动日志验证；小智账号绑定及实际转写仍需真机验收。`build/`、`release/`、`node_modules/`、生成的 `sdkconfig` 和 `managed_components/` 不提交 Git。

中文提示音由 [scripts/build-voice-prompts.py](scripts/build-voice-prompts.py) 使用 `edge-tts-chinese` 的云健男声生成，再转换为 8 kHz 单声道 μ-law 并打包为 `firmware/easyinput-monitor/main/assets/prompts.bin`。

## 烧录

在“设备 → 固件升级”中选择包含 `firmware.json`、bootloader、分区表和应用镜像的完整目录。网页会校验清单、文件大小和 SHA-256，识别到 ESP32-S3 后要求再次确认才写入。

自动进入下载模式失败时，保持开发板开机，短按并松开一次 BOOT，再重试并选择 ESP32 下载端口。板上没有独立 RESET/EN 键；更新完成后关机再开机恢复正常运行。

## 尚未完成或需要真机验收

- 所有红色慢闪状态统一为亮 0.5 秒、熄灭 2 秒；五颗 WS2812 点亮亮度为 1%。
- 固件编译和自动化测试不能替代板载麦克风、扬声器、GPIO8 共享电源、灯序、按键方向和声音水平/音质的实板验证。
- 实时麦克风需要开发板通过 Wi-Fi 直连云服务；蓝牙网关继续承载历史语音和状态。网络中断会停止实时采集。
