# 语音时间线

本功能对应网页和固件 0.4.1。网页使用 `https://studio.leige.online`，开发板通过 `wss://easy.leige.online` 连接共享语音房间；没有 Wi-Fi 直连时，一台保持打开的蓝牙网关网页可以转发开发板状态和语音。

## 统一时间线

- 不区分电脑数量，不设置 S1～S4 / S8 电脑槽位。
- 网页录音和开发板录音进入同一条时间线，按服务端时间排序，最新消息显示在最上方。
- 只接受语音消息。网页文字输入、用户文字转语音和 `/tts` 接口已经移除。
- “开发板已播放”只在扬声器完整播放并完成 DMA 尾音后回执；网页播放或中断播放不会标记已读。
- 云端保留最近 100 条已提交语音。新消息优先淘汰已读内容，不淘汰未读语音。

## 按键

| 按键 | 行为 |
| --- | --- |
| S1 短按 | 直接播放前一条历史语音，包括已读语音；连续按继续向更早的语音回听，到最早一条后不循环 |
| S1 长按 3 秒 | 播报“是否所有未读语音标记为已读？”，灯 1 常亮并进入批量已读确认状态 |
| S2 短按 | 播放最早的一条未读语音，并将该条设为 S1 的回听起点；没有未读时提示“暂无语音” |
| 批量确认中 S2 长按 3 秒 | 将所有未读语音标记为已读；云端确认后播报成功并熄灭灯 1，不删除历史语音和音频；失败或超时播报失败 |
| 批量确认中其他键或 S2 短按 | 取消确认，灯 1 熄灭 |
| 播放中按 S1 / S2 | S1 一次按键直接切换到前一条历史语音；S2 从第一条未读语音开头播放，并重设回听起点 |
| 播放中按其他键 | 立即停止语音播放；本次按键不再触发其他短按动作 |
| S3 短按 | 进入每日闹钟设置，立即播报当前值；右旋加 30 分钟、左旋减 30 分钟，范围 00:00～23:30 |
| S3 旋转 | 每次旋转立即播报更新后的完整时间 |
| S3 数字播完后静置 3 秒 | 保存闹钟并播报“每日闹钟已设置好” |
| S3 长按 1.2 秒 | 取消每日闹钟 |
| S4 短按 | 进入倒计时设置并立即播报默认 30 分钟；右旋加 1 分钟、左旋减 1 分钟，范围 1～60 分钟 |
| S4 旋转 | 每次旋转立即播报更新后的分钟数 |
| S4 数字播完后静置 3 秒 | 保存并立即开始倒计时，播报“倒计时已设置好，马上开始倒计时” |
| 倒计时中任意键 | 停止并取消倒计时 |
| S5 短按 | 先提示开始录音，随后最多录制 20 秒 |
| S6 录音中 | 结束录音并发送 |
| S6 满 20 秒后 | 发送已经暂存的录音 |
| S7 短按 | 开始实时麦克风；网页总开关关闭或网络不可用时提示并拒绝开始 |
| S7 实时中 S8 短按 | 结束实时麦克风并语音提示“实时监听已结束” |
| S8 短按（非实时中） | 播报开发板是否联网和电脑端在线人数；离线时人数播报为未知 |
| 旋钮长按 3 秒 | 保留手机热点配网入口，不触发短按动作 |

除 S3 和旋钮外，未定义长按动作的按键即使按住超过 1.2 秒，也会在松开时作为一次短按处理，不会吞掉操作。

每次 S2 开始播放后，S1 都从这条语音往前回听。例如 S2 播放第 5 条，连续按 S1 播放第 4、3 条；再按 S2 播放当前第一条未读（例如第 6 条），下一次 S1 就播放第 5 条。完整播放后的已读回执保留回听位置，中断播放仍不会标记已读。

尚未建立回听位置时，S1 以第一条未读为参照播放它的前一条；全部已读时从最新一条历史语音开始回听。没有任何消息时提示“暂无语音”。

S6 在录音中或“录音已保存，等待发送”提示播放期间优先执行结束/发送，不会被通用提示音打断逻辑吞掉。

每日闹钟保存在板端 NVS，依赖一次有效的网络时间同步。倒计时使用板端单调时钟，断网仍可运行。开发板时间固定使用中国标准时间 UTC+8。

S8 所说的“开发板在线”以最近 8 秒内语音服务确认的联网证据为准，不只看 Wi-Fi 关联。电脑人数来自语音服务最新在线状态，同一浏览器身份开启多个标签页也只算一人。开发板未联网时无法可靠取得人数，因此播报为未知。

## 灯效

WS2812 点亮亮度固定为最低档 1%。所有红色慢闪统一为亮 0.5 秒、熄灭 2 秒，周期 2.5 秒。

| 灯 | 行为 |
| --- | --- |
| 灯 1 | 有未读语音时红色慢闪；批量已读确认期间常亮；全部已读或无记录时熄灭 |
| 灯 2 | 录音时红色常亮；发送或待重试时红色慢闪 |
| 灯 3 | 实时监听时红色慢闪；其他情况熄灭 |
| 灯 4 | 有电脑端语音页面在线时红色慢闪；无人在线或开发板未联网时熄灭 |
| 灯 5 | 已设置闹钟时红色常亮；倒计时运行中红色慢闪；倒计时优先 |

## 录音与离线重试

录音结束先写入 `voice_outbox` Flash 分区，再上传。该分区包含 8 个固定录音槽，每槽最多 20 秒；缓存满时拒绝开始新录音，保护已有录音。

每条录音使用稳定消息 ID。云端确认完整提交后才释放缓存；上传失败或等待回执超过 12 秒后，每 3 秒重新协商并续传。确认入群后释放录音并播报“发送成功”。缓存写入失败时保留 PSRAM 中的录音并提示保持供电。

满 20 秒自动结束但用户尚未按 S6 时，录音已保存但不启动上传；按 S6 后才开始发送。

## 实时麦克风

- 网页“实时监听”开关是共享房间设置，默认关闭。
- S7 先播放“开始实时监听”，随后开启板载麦克风。
- 板端通过二进制 WebSocket 帧发送 16 kHz 单声道 PCM16，每 20 ms 一帧、320 个采样。
- 板端在同一有序 WebSocket 上同步发送 `realtime.start`，随后立即发送实时音频；云端 ACK 仅用于诊断。网页使用约 60 ms 抖动缓冲播放。
- 实时缓冲超过约 250 ms 时丢弃旧队列，避免延迟持续累积。
- 实时音频只通过语音房间转发，不写入云端历史或 Flash。
- S7 后按 S8、网页关闭开关、网络中断或蓝牙网关断开都会停止采集。
- 当前 PCM16 实时流要求开发板通过 Wi-Fi 直连云服务；蓝牙网关仍可承载历史语音和状态，但不承载实时音频。

## 提示音

提示音使用 `edge-tts-chinese` 的云健男声 `zh-CN-YunjianNeural`、语速 `+35%`，生成后裁掉首尾长静音并转换为 8 kHz 单声道 μ-law。闹钟时间和倒计时分钟使用完整短语，打包为 `prompts.bin`；其他数字、分钟和在线人数仍在运行时拼接。

重新生成：

```sh
python3 scripts/build-voice-prompts.py
```

上游许可见 [EDGE_TTS_LICENSE.txt](EDGE_TTS_LICENSE.txt)。

## 网页

网页只保留两个入口：

- **语音**：统一时间线、网页录音、实时监听总开关和 S1～S8 操作说明。
- **设备**：开发板在线状态、USB/蓝牙连接、Wi-Fi、语音服务配对和固件升级。

网页已移除文字消息、电脑槽位、灯光编辑、音频测试、性能、存储、分区、输入事件流和演示模式。

## 验证边界

本轮完成的软件验证包括网页类型检查、网页/云端自动化测试、Cloudflare 类型检查、提示音包结构检查、ESP-IDF 5.5.5 固件编译。固件构建后应用分区仍有约 50% 空间。

以下项目必须由实板确认，不能用编译或自动化测试代替：

1. 灯 1～5 的实体顺序、1% 最低亮度和统一慢闪节奏。
2. S1 连续回听更早语音、S2 重设回听起点、播放中一次按键切换的行为，以及 S3 旋钮方向。
3. S2 完整播放后的已读回执与中断播放不标已读。
4. S5/S6 的提示音、20 秒自动结束、Flash 缓存和发送成功提示。
5. 每日闹钟跨重启保存、NTP 时间同步和到点提示。
6. 倒计时每秒滴答、每分钟长滴答与剩余分钟播报。
7. S7 实时声音延迟、断续、底噪和 Wi-Fi/蓝牙网关差异。
8. 灯 4 的 0.5 秒亮、2 秒灭周期，以及 S8 对 0、1、10、128 人在线时的中文播报。
9. 共享 GPIO8 电源、麦克风声道、扬声器音量以及录音回放音质。
