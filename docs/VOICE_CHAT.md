# 多电脑语音群

本功能对应网页 0.2.1、固件 0.2.4。线上地址为 https://studio.leige.online，云端地址为 wss://easy.leige.online。网页、开发板和蓝牙网关共享同一个云端房间。

## 日常使用

网络页只显示“开发板状态：在线 / 离线”；在线时显示 Wi-Fi 或蓝牙网关。电脑能够连上群聊服务器不等于开发板在线；必须持续收到开发板的新状态，超过 8 秒没有新状态则离线。首次加载和网络重连期间，未获得证据前显示离线，不沿用历史在线状态。

所有电脑直接打开同一网址即可同步状态、留言和开发板已读。浏览器首次进入时生成随机身份，保存在本浏览器的 localStorage；同一电脑的不同浏览器 / 浏览器配置文件视为不同客户端，清空站点数据也会生成新身份。同一配置文件的多个标签页共用一个身份。

前四个身份固定对应 S1、S2、S3、S4，第五个及后续身份统一对应 S8。不因客户端暂时离线重排绑定。界面显示本机名称及对应按键，灯号也在群聊上方显示。当前允许最多 128 个已登记身份。

## 按键和灯

| 资源 | 动作 |
| --- | --- |
| S1～S4 短按 | 对应电脑有未读时，按顺序播放最早未读；全部已读后重播最近一条未清除留言 |
| S8 短按 | 同样规则，汇总所有第 5 台及之后电脑的留言 |
| S1～S4 / S8 长按 1.2 秒 | 清除对应通道的全部已读语音；未读不清除。长按不会再触发短按播放 |
| 灯 1～4 | 对应 S1～S4；存在未读为红色，仅有已读为绿色，无未清除留言则熄灭 |
| 灯 5 | 录音中橙色闪烁，优先于发送和 S8 留言灯态；发送中黄色闪烁，失败 / 离线待发时黄色常亮。云端确认成功后恢复 S8 的红 / 绿 / 灭状态 |
| S5 按下 | 成功开始板载麦克风录音后，第 5 灯立即亮橙色并闪烁（亮 / 灭各约 350 ms） |
| S6 按下 | 结束录音，立即退出橙色闪烁，再暂存并发送到群里 |
| S7 按下 | 请求云端确认当前路径，语音播报 Wi-Fi / 蓝牙网关 / 离线；录音或留言播放结束后播报 |
| 旋钮转动 | 每格调节 5%，范围 0～100%，初始 20%；方向仍待实物确认 |
| 旋钮短按 | 切换允许 / 禁止 S8 播放，默认允许；音量和此开关在停止操作 1 秒后写入 NVS |
| 旋钮长按 3 秒 | 开启 / 延长 2 分钟手机热点配网，保留现有配置及缓存；不会触发短按 |
| 录音满 60 秒 | 自动结束，退出橙色闪烁并发送；随后沿用黄色发送灯态 |

“开发板已读”只在扬声器完整播放并完成 DMA 尾音后，由开发板回执确认。下载完成、开始播放、网页播放、播放失败或提前停止都不会把开发板留言标成已读。若播放过程中又收到新留言，该路仍保持红灯。

长按清除会删除云端音频，网页保留“已在开发板清除”的已读记录；重复播放不再包含它。通道有未读时，清除已读后仍为红灯。有留言的灯由群聊管理；全部清除后熄灭并释放手动灯光控制。灯珠逻辑顺序为串联 1～5，实体位置仍需装配后核对。

关闭 S8 播放时仍接收和保留这些留言，未读不会被标记已读；正在播放的 S8 留言会停止，完整播放确认前仍未读。重新开启后可按 S8 播放。长按 S8 仍仅清除已读。

录音结束先保存到独立 Flash 缓存，再上传。缓存最多 8 条，每条最多 60 秒；满时拒绝新录音并播报提示，保护已有录音。Flash 分区为 `voice_outbox`，地址 `0x400000`、大小 4 MiB；原 NVS、应用分区地址保持不变。保存完成的录音断电后仍保留；正在录制、尚未完成保存的录音不能保证断电保留。保存异常时保留 PSRAM 中的录音、提示保持供电，直到保存成功；此时禁止覆盖它。

每条录音使用稳定消息 ID。云端确认完整提交后才释放缓存；失败或等待分片回执超过 12 秒，进入等待状态，3 秒后重新协商并续传。没有有效联网证据时每 3 秒探测，恢复后继续发送，发送重试不写 Flash。等待重试时可以录制下一条、播放留言、调节音量和按 S7，前台操作会暂停上传，随后自动续传。录音与扬声器留言播放互斥，提示音排队播放。

## 网页留言和文字转语音

点击“录一条语音”，首次允许浏览器麦克风权限；点击“结束并发送”，或满 60 秒自动结束。发送失败时保留录音草稿，可重试或放弃。文字发送时先用在线 Edge 朗读合成，再转成开发板和网页通用的音频格式，成功后才发群；合成失败保留原文，不伪装成发送成功。

采用 edge-tts-chinese 的云健男声 `zh-CN-YunjianNeural`、语速 `-10%`，不修改原文。输入最多 300 字，转换后超过 60 秒会提示缩短。运行时适配代码在 `cloudflare/src/tts.ts`；无须各电脑安装 Python。Edge 是在线朗读服务，提供方的可用性不由本项目保证。上游许可见 [EDGE_TTS_LICENSE.txt](EDGE_TTS_LICENSE.txt)。

网页音频统一为 8 kHz 单声道 G.711 μ-law；播放时封装成 16-bit PCM WAV。固件用板载 16 kHz I2S 捕获并降采样，播放时升采样到 16 kHz 双声道；语音留言的板端音量初始为 20%。最长一条音频占 480,000 字节。

## 首次连接

安卓 / iPhone 均可用手机热点配网，无需先连接蓝牙，也不依赖网页蓝牙支持：

1. 长按旋钮 3 秒，等待配网语音提示。
2. 手机 Wi-Fi 连接 `EasyInput-Setup-XXXX`（XXXX 为板端 MAC 末两字节），密码 `easyinput`。手机提示此热点无法上网时，选择保持连接。
3. 在浏览器**地址栏**输入 `http://192.168.4.1`，填写 2.4 GHz Wi-Fi 名称和密码。首次使用还需云端配对码；已有配对配置可留空，更换错误配对码可展开对应区域。
4. 保存后切回日常网络，打开 https://studio.leige.online 查看状态。保存成功表示配置已写入，不代表已连上互联网。

热点在 2 分钟后自动关闭；超时可再次长按。进入热点模式不主动断开原 Wi-Fi，保存新 Wi-Fi 时才切换连接；手机配网期间仍保留蓝牙网关能力。设置接口仅在配网窗口内、经热点地址可用。热点有 WPA2 密码；页面内使用每次配网窗口随机生成的提交凭据。未配置时也不会自动清除 NVS 或录音。

也可通过“网络 → 首次连接 / 更换 Wi-Fi”连接 USB 或加密蓝牙配置。Wi-Fi 和配对信息保存进开发板 NVS；Wi-Fi 密码不保存在网页 localStorage，也不通过群聊或遥测传输。之后开发板自己连接 Wi-Fi，手机可离开。

Wi-Fi 直连优先，电脑不必留在开发板旁边。开发板没有可用 Wi-Fi 时，已连接它的蓝牙网页可以充当网关，转发状态和语音；该电脑需要有网且保持网页运行。浏览器授权和系统休眠限制依然适用，关闭网关网页或让电脑休眠会中断这条路径。其他电脑只需打开网址。

## 云端保留和重传

保留最近最多 100 条已提交消息，优先淘汰已读电脑留言或旧的开发板回复，绝不为新消息淘汰未读电脑留言。100 条全部是未读时提示先播放再发送。长按清除是显式释放对应已读音频。上传分片在完整提交前不出现在群里；连续 10 分钟没有新上传进度或重连协商的上传会清理。

每条音频以 768 字节分片传输，每片由云端确认，支持同一消息 ID 重试、分片续传和重复提交去重。开发板启动及周期同步元数据，按下播放键后才下载对应语音；不会把所有历史音频同时载入 PSRAM。云端为板端录音保留小型提交回执，即使该音频已从历史淘汰，丢失确认的板端重试也不会重复入群。协议见 [PROTOCOL.md](PROTOCOL.md)。

## 本次验证与待验收

软件检查：网页构建、云端类型检查通过；消息队列 / 多客户端广播 / 只清已读 / 在线路径选择 / 音频编码与 TTS 适配共 43 项自动化测试通过。线上文字转语音接口已返回 HTTP 200，生成的 MP3 可解析为 24 kHz 单声道、时长 5.88 秒；实际听感仍待用户试听。固件使用 ESP-IDF 5.5.5 从 sdkconfig.defaults 生成配置后构建，导出文件的大小和 SHA-256 校验一致；导出目录为 release/firmware/0.2.4-v2-monitor/。

本机 ESP-IDF 组件管理器调用 psutil 时受到沙箱限制。本次复用已安装、锁定的 WebSocket 组件，关闭组件管理器自动发现，并显式传入同一组件路径；没有安装或升级依赖。构建使用 `build/sdkconfig-voice`，未将临时配置改成维护入口。

Flash 缓存模块还通过本机 C 模拟测试：8 条完整 60 秒录音重启恢复、队满保护、音频和头部写入中断不发布残片、确认失败不释放录音、稳定 ID 跨重启保留。这些是内存模拟 Flash 的结果，不能代替物理掉电实验。固件编译通过，应用分区仍有约 57% 空闲。

固件 0.2.2 在实板上验证了启动、Wi-Fi 和录音橙色闪烁逻辑，但发现开发板尚未同步系统时间时会间歇性把新 TLS 证书判定为“尚未生效”，导致网页在线状态断开。0.2.3 在获得 Wi-Fi IP 后通过 `ntp.aliyun.com` 启动 SNTP，并只在系统时间有效后建立云端 WSS；云端连接后再每 3 秒发送一个轻量在线心跳。实板测试又发现 TLS 握手时内部 RAM 最低仅剩约 13 KB、最大连续块约 3.5 KB，连接可能因此超时。0.2.4 将状态、BLE 发送和云端辅助线程迁移到 PSRAM；按键扫描、音频实时循环、语音 Flash 缓存、USB 固件操作和配网任务继续使用内部 RAM，避免在 Flash 缓存关闭时从 PSRAM 栈访问 Flash。云端只上传轻量在线心跳和实际语音群消息；完整遥测继续通过 USB/BLE，避免每秒上传数 KB 的大状态帧耗尽 TLS 发送缓冲。橙灯的实际颜色、闪烁以及 S6 / 60 秒结束后的切换仍需物理验收；上列 43 项测试是网页和云端部分的既有检查结果。

实板验证结果：0.2.4 启动内部 RAM 可用约 61 KB；SNTP 在约 3 秒内同步，云端证书验证及 WSS 连接成功。网页显示“在线 · Wi-Fi”，连续观察 60 秒未出现云端断开日志。剩余待验收项为橙灯实际颜色/闪烁、S6 与 60 秒自动结束、音量旋钮、S7 播报、语音收发和手机配网。

9 条提示音由 `edge-tts-chinese`（云健男声、-10%）生成，转换成 8 kHz 单声道 μ-law，存于 `firmware/easyinput-monitor/main/assets/`。S7 用最近 8 秒内服务器确认的路径，未获确认时播报离线；蓝牙连接本身不代表能上网。新增 `wifi`、`ble`、`offline`、`setup`、`s8_on`、`s8_off`、`full`、`save_failed`、`setup_failed` 音频资源。格式已转换，实际听感待试听。

CH340 焊接完成后仍需实际烧录并验证：

1. Wi-Fi 配置保存、断电重启自动在线；断网 / 断电后各电脑一致离线，恢复后上线。
2. 关闭板端 Wi-Fi，保留一台蓝牙网关，其他电脑看到“蓝牙网关”；关闭该网关后离线。
3. 至少 6 个独立浏览器身份发送留言，核对 S1～S4 与 S8、实体灯序和红灯。
4. 逐条播放：播放完整才同步已读；有剩余未读保持红灯，全部读完变绿；短按重播。
5. 混合已读与未读，长按清除已读但保留未读；全部读完再清除后灯灭，刷新网页不恢复已清语音。
6. S5 成功录音后第 5 灯橙色闪烁，S6 或满 60 秒结束后停止橙闪并转入黄色暂存 / 发送灯态；全群收到并可播放，检查麦克风声道、幅度、扬声器声音和共享电源。录音未能启动时不应显示橙闪。
7. 断网录满 8 条，检查黄灯常亮、缓存满提示；恢复网络后黄灯闪烁，确认入群后恢复 S8 灯态。重试失败后等待 3 秒；云端已提交但丢失确认时不重复入群。
8. 完成缓存写入后断电重启，核对录音仍按顺序发送；分别检查保存过程中断电与已保存后的断电行为。
9. 旋钮音量即时变化、方向与静音；短按禁止 S8 后未读仍在，恢复后可播放；重启后音量和开关保存。长按不触发短按。
10. S7 分别播报 Wi-Fi、蓝牙网关与离线；录音 / 播放时不会被提示音截断。
11. 安卓 / iPhone 手机热点配网、已有 Wi-Fi 更换、热点 2 分钟关闭，以及断电重启自动连接。首次错误配对码可以重新填写。
12. 网页录音权限、真实语音收听与文字朗读听感由用户确认。编译 / 自动化测试不能代替这些物理现象。

本轮不烧录，也不将任何模拟状态记作真机验收。
