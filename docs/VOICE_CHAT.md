# 语音时间线

2026-10-29 已发布网页 0.4.6，线上首页、应用脚本及 Service Worker 与本地构建一致；固件 0.4.16 已烧录，串口确认版本号及应用正常启动，配套云端网关沿用现有部署。S6 小智绑定、回复播放与多轮交谈仍需实板联网试听验收。网页使用 `https://studio.leige.online`，开发板通过 `wss://easy.leige.online` 连接共享语音房间；没有 Wi-Fi 直连时，一台保持打开的蓝牙网关网页可以转发开发板状态和语音。

## 统一时间线

- 不区分电脑数量，不设置 S1～S4 / S8 电脑槽位。
- 网页录音、开发板录音和已有转写文字保存在同一条时间线，按服务端时间排序，最新消息显示在最上方。
- 网页和开发板发送语音；旧版文字继续可查看，未完成的旧版文字继续补传。S6 小智对话不写入时间线。文字不参与扬声器播放、音频下载或语音 ZIP，网页不提供文字输入或文字转语音。
- “开发板已播放”只在扬声器完整播放并完成 DMA 尾音后回执；网页播放或中断播放不会标记已读。
- 云端最多保留 5000 条已提交消息（语音或文字），语音每条最长 20 秒，文字每条最多 1000 个 UTF-16 单元。满额时淘汰最早的开发板录音或已读语音，保护未读网页留言；如果 5000 条全部是未读网页留言，新发送会提示先播放。

## 按键

| 按键 | 行为 |
| --- | --- |
| S1 短按 | 直接播放前一条历史语音，包括已读语音；连续按继续向更早的语音回听，到最早一条后不循环 |
| S1 长按 3 秒 | 播报“是否所有未读语音标记为已读？”，灯 1 常亮并进入批量已读确认状态 |
| S2 短按 | 播放最早的一条未读语音，并将该条设为 S1 的回听起点；没有未读时提示“暂无语音” |
| 批量确认中 S2 长按 3 秒 | 将所有未读语音标记为已读；云端确认后播报成功并熄灭灯 1，不删除历史语音和音频；失败或超时播报失败 |
| 批量确认中其他键或 S2 短按 | 取消确认，灯 1 熄灭 |
| 播放中按 S1 / S2 | S1 一次按键直接切换到前一条历史语音；S2 从第一条未读语音开头播放，并重设回听起点 |
| 播放中按其他键 | 立即停止语音播放；本次按键不再触发其他短按动作 |
| S3 短按 | 进入每日闹钟设置，立即播报当前值；右旋加 30 分钟、左旋减 30 分钟，范围 00:00～23:30 |
| S3 旋转 | 每次旋转立即播报更新后的完整时间 |
| S3 数字播完后静置 3 秒 | 保存闹钟并播报“每日闹钟已设置好” |
| S3 长按 1.2 秒 | 取消每日闹钟 |
| S4 短按 | 进入倒计时设置并立即播报默认 30 分钟；右旋加 1 分钟、左旋减 1 分钟，范围 1～60 分钟 |
| S4 旋转 | 每次旋转立即播报更新后的分钟数 |
| S4 数字播完后静置 3 秒 | 保存并立即开始倒计时，播报“倒计时已设置好，马上开始倒计时” |
| 倒计时中任意键 | 停止并取消倒计时 |
| S5 短按 | 先提示开始录音，随后最多录制 20 秒 |
| S5 再次短按 | 录音中结束并发送；满 20 秒后发送已经暂存的录音 |
| S5 长按 3 秒 | 取消本次正在录制或尚未发送的录音；松手不触发发送 |
| S6 短按 | 开始与小智实时语音对话，回答播完后自动继续听 |
| 小智连接或对话中 S6 短按 | 立即停止收音和回答播放，并关闭会话 |
| 小智对话中其他功能键或旋钮按压 | 忽略本次按键，松手不触发普通功能；旋钮旋转仍可调音量 |
| S7 双击 | 依次播报妈妈高压、妈妈低压、爸爸高压、爸爸低压的最近保存值 |
| S8 双击 | 依次播报爸爸血糖、妈妈血糖的最近保存值 |
| S7 短按 | 依次循环妈妈高压 → 妈妈低压 → 爸爸高压 → 爸爸低压，进入本次记录并播报当前调整值 |
| S8 短按 | 依次循环爸爸血糖 → 妈妈血糖，进入本次记录并播报当前调整值 |
| 测量记录中旋钮短按 | 第一次进入精细调整，第二次确认保存；不再静置自动保存 |
| 测量记录中旋钮长按 3 秒 | 取消本次记录，保留已保存记录，不进入配网 |
| 非记录编辑中旋钮长按 3 秒 | 保留手机热点配网入口，不触发短按动作 |

S7/S8 双击窗口为第一次松开至第二次按下 **≤400 毫秒**；第二次松手后执行双击，单击在窗口结束后执行。窗口内旋转或按下旋钮会直接进入待选测量编辑；双击查询不会推进人物轮换或保存记录。S5/S6 短按在松手时执行，不等待双击窗口；连续两次按下 S5 按普通录音启停处理，连续两次按下 S6 按对话启停处理。S4 继续设置倒计时。

S1、S2、S5 和旋钮的长按阈值为 3 秒，S3 为 1.2 秒。S4、S6、S7、S8 未定义长按动作，按住后松开仍作为一次短按处理。

每次 S2 开始播放后，S1 都从这条语音往前回听。例如 S2 播放第 5 条，连续按 S1 播放第 4、3 条；再按 S2 播放当前第一条未读（例如第 6 条），下一次 S1 就播放第 5 条。完整播放后的已读回执保留回听位置，中断播放仍不会标记已读。

尚未建立回听位置时，S1 以第一条未读为参照播放它的前一条；全部已读时从最新一条历史语音开始回听。没有任何消息时提示“暂无语音”。

S5 在录音中或“录音结束，短按 S5 发送，长按 S5 取消”提示播放期间优先执行录音控制，不会被通用提示音打断逻辑吞掉。取消已暂存录音时只释放本次录音的槽位；已经开始发送的录音继续按原有流程重试。

每日闹钟保存在板端 NVS，依赖一次有效的网络时间同步。倒计时使用板端单调时钟，断网仍可运行。开发板时间固定使用中国标准时间 UTC+8。

## 已有记账记录

本次移除记账输入和 S6 双击汇总入口。已有板端 `ledger` NVS 数据、云端记账记录和 CSV 导出保留；旧固件留下的待同步记录仍通过 Wi-Fi 或选中的蓝牙网关补传，云端按稳定编号去重，收到确认并写入本地存储后才移出待同步队列。

设备页「下载记账 CSV」导出云端已同步的全部记账，包含记录编号、记账时间、时间状态、金额、人民币单位、云端接收时间和开机后毫秒数。时间均为 UTC；时钟未校准时记账时间留空，接收时间另列。导出开始后新到的记录留待下一次导出，板端待同步数量单独显示。

## S6 小智实时语音对话

短按 S6，开发板连接小智并开始收音。用户说话由服务端断句，小智回答通过板载扬声器播放；回答播完后自动继续听，保持会话并支持多轮交谈，无需每轮按键。对话不受普通录音的 20 秒时长限制，服务端可能有自己的空闲或会话限制。

当前通过小智 `listen.start` 的 `auto` 模式轮流说话：收到小智回答时暂停麦克风采集；同时等到服务端 `tts.stop` 和本地播放缓冲、DMA 尾音完成后，才发送下一轮 `listen.start` 并恢复收音。回答期间用户说话不会采集，需等回答播完再说。旋钮旋转可调整音量，音量提示及到点闹钟、倒计时播报延后，避免设备录入自己的提示音。

再次短按 S6，在松手时立即停止收音和回答播放，再异步关闭会话；连接过程中也可这样取消。不沿用旧转写功能等待 20 秒尾句的流程。对话期间其他功能键和旋钮按压被忽略，松手也不触发普通动作。

小智对话与网页实时监听、普通录音互斥；网页监听已开启、录音或发送繁忙时拒绝开始对话，保留当前任务。小智对话中的新监听请求也不会开启另一条麦克风路径。S6 不控制网页实时监听开关。对话中的用户识别文字和小智回答均不发送到网页时间线，已有转写文字和旧版未发完的文字继续保留、补传。

上行使用 16 kHz 单声道、60 ms 帧的 Opus。下行校验服务端协商的音频参数，再通过 Opus 解码器输出 16 kHz 单声道 PCM 供板端流式播放；采集和播放使用有界缓冲。网络中断、协议或音频处理失败、缓冲溢出时停止会话并提示失败，重新短按 S6 可重试。缓冲用于网络调度，不提供离线对话或录音恢复。

小智沿用开发板保存的 Wi-Fi，需要开发板直接联网，蓝牙网关不能代替小智连接。首次使用通过小智官方 OTA 接口获取激活信息；若需要绑定，会播报激活码并在串口显示。在 `xiaozhi.me` 添加设备并填写该验证码，完成后再次短按 S6 开始对话。固件只使用 OTA 返回的连接及激活配置，不安装其中的官方固件；若只有 MQTT 配置而没有安全 WebSocket 地址，会提示连接失败。

需要更换网络时，在非记录编辑、非小智对话状态长按旋钮 3 秒，手机连接 `EasyInput-Setup-` 加设备 MAC 后四位的热点（密码 `easyinput`），打开 `http://192.168.4.1`，填写 2.4 GHz Wi-Fi 名称和密码后保存；已有云端配置时，云端配对码可留空。热点开放 2 分钟。小智验证码与 EasyInput 云端配对码用途不同。

对话期间测量、记账和汇总的后台同步及相关 NVS 确认延后，退出后重试；旧版待发送文字仍使用原稳定编号与确认机制补传。小智账号绑定、识别断句、回复声音、多轮收听与播放切换必须由实板联网验收，不能由编译或本地测试证明。

## 血压与血糖记录

单击以最近成功保存值作为调整起点，无历史时使用下表默认值；直接播报当前调整值。查询最近值改为双击 S7/S8；对应项目未记录时明确提示“暂无上次记录”。

| 项目 | 范围 | 首次初始值 | 快速每格 | 精细每格 |
| --- | --- | --- | --- | --- |
| 高压 | 80～220 | 130 | ±10 | ±1 |
| 低压 | 50～120 | 70 | ±10 | ±1 |
| 血糖 | 3.0～20.0 | 7.5 | ±1.0 | ±0.1 |

每次选择新项目都从快速调整开始，第一次短按旋钮进入精细调整并语音提示，第二次短按确认保存。旋转时播报当前值，范围到边界后保持边界值；快速旋转会用最新数值打断旧播报，避免排队积压。

静置不会自动保存；仅听取上次值不会产生新记录。第二次短按明确确认后，即使数值未变也保存为一次新记录，并播报项目、数值及“已记录”。任一阶段按满 3 秒取消后，松开不触发短按、保存或配网。

未保存时按 S7/S8 会丢弃当前草稿并切换下一项，其他功能键离开记录也丢弃草稿。六项最近值和每次成功保存的待同步历史一起存入板端 NVS，离线可用，断电保留。联网后通过 Wi-Fi 或蓝牙网关逐条补传，云端按记录编号去重保存；收到确认后才移出板端队列。板端最多保留 64 条待同步记录，满时或存储失败会播报保存失败，不覆盖旧记录，也不替换上次成功值。相同数值的多次保存仍是独立历史。

在设备页点击「下载历史 CSV」，可导出云端已同步的全部测量记录，包含编号、测量时间、时间状态、人物、项目、数值、单位、接收时间和开机后毫秒数。血糖单位为 mmol/L，血压为 mmHg；时间使用明确的 UTC ISO 格式。未校准设备时钟的测量时间留空并注明未知，云端接收时间不冒充测量时间。板端仍有待同步记录时会显示数量；开发板离线时可能还有未同步数据。旧固件只保留最近值，升级后保留这些值用于回读，但无法补出旧的测量历史。

## 灯效

WS2812 点亮亮度固定为最低档 1%。所有红色慢闪统一为亮 0.5 秒、熄灭 2 秒，周期 2.5 秒。

| 灯 | 行为 |
| --- | --- |
| 灯 1 | 有未读语音时红色慢闪；批量已读确认期间常亮；全部已读或无记录时熄灭 |
| 灯 2 | 录音时红色常亮；发送或待重试时红色慢闪 |
| 灯 3 | 实时监听时红色慢闪；其他情况熄灭 |
| 灯 4 | 有电脑端语音页面在线时红色慢闪；无人在线或开发板未联网时熄灭 |
| 灯 5 | 已设置闹钟时红色常亮；倒计时运行中红色慢闪；倒计时优先 |

## 录音与离线重试

录音结束先写入 `voice_outbox` Flash 分区，再上传。该分区包含 8 个固定录音槽，每槽最多 20 秒；缓存满时拒绝开始新录音，保护已有录音。

每条录音使用稳定消息 ID。云端确认完整提交后才释放缓存；上传失败或等待回执超过 12 秒后，每 3 秒重新协商并续传。确认入群后释放录音并播报“发送成功”。缓存写入失败时保留 PSRAM 中的录音并提示保持供电。

满 20 秒自动结束但用户尚未再次短按 S5 时，录音已保存但不启动上传；再次短按 S5 后才开始发送，长按 S5 3 秒可取消本次暂存录音。

## 实时麦克风

- 网页“打开实时麦克风 / 关闭实时麦克风”直接启停板载麦克风，是共享房间开关，默认关闭；其他网页同步状态。
- S7/S8 用于测量记录或双击查询，不启停实时采集，监听期间仍可操作。为避免录音路径冲突，监听期间 S1～S5 暂停操作，S6 不会启动小智对话；已有普通录音或小智对话进行中则拒绝打开实时麦克风。
- 板端通过二进制 WebSocket 帧发送 16 kHz 单声道 PCM16，每 20 ms 一帧、320 个采样。
- 板端在同一有序 WebSocket 上同步发送 `realtime.start`，随后立即发送实时音频；云端 ACK 仅用于诊断。网页使用约 60 ms 抖动缓冲播放。
- 实时缓冲超过约 250 ms 时丢弃旧队列，避免延迟持续累积。
- 实时音频只通过语音房间转发，不写入云端历史或 Flash。
- 网页关闭开关、开发板 Wi-Fi 直连断开或心跳超时都会停止采集并同步关闭状态；启动 8 秒未成功会取消打开请求。
- 当前 PCM16 实时流要求开发板通过 Wi-Fi 直连云服务；蓝牙网关仍可承载历史语音和状态，但不承载实时音频。

## 提示音

提示音使用 `edge-tts-chinese` 生成后裁掉首尾长静音并转换为 8 kHz 单声道 μ-law。测量项目、保存取消、步进提示与其余常规提示沿用云健男声 `zh-CN-YunjianNeural`、语速 `+35%`；既有音量数字沿用晓晓女声 `+20%`。闹钟时间和倒计时分钟使用完整短语，打包为 `prompts.bin`；测量数值在运行时拼接，血糖总是播报一位小数。

重新生成：

```sh
python3 scripts/build-voice-prompts.py
```

上游许可见 [EDGE_TTS_LICENSE.txt](EDGE_TTS_LICENSE.txt)。

## 网页

网页只保留两个入口：

- **语音**：统一时间线、网页录音、实时监听状态及开关、S1～S8 操作说明。新增「下载全部语音 ZIP」和「顺序播放全部」；全部指云端当前保留的最多 5000 条语音，与网页已经加载的页数无关。网页首屏显示最新 50 条，可点击「加载更早消息」继续翻页；总条数和未读数覆盖整个群。ZIP 每包最多 100 条，文件按全局顺序和 UTC 时间命名；第一包完成后点击「下载第 N 包」继续。失败可重试当前包。连续播放先取得完整历史索引，再从最早到最新逐条下载播放，支持随时停止，网页播放不改变开发板未读状态。导出开始后新到的语音留待下次；若期间旧语音被清理会提示重试。
- **设备**：显示每日闹钟、倒计时、实时监听状态，以及血压血糖历史和记账历史 CSV 下载。USB、蓝牙连接按钮及状态集中放在折叠的「连接 Wi-Fi 与语音服务」配置区，顶部仅保留开发板在线状态和网页版本。

网页已移除手工文字输入、电脑槽位、灯光编辑、音频测试、性能、存储、分区、输入事件流和演示模式。

## 验证边界

软件检查应覆盖 S5 普通录音启停与长按取消、S6 对话启停和取消连接、S7/S8 的 400 毫秒双击边界、WebSocket 文本及二进制分片、下行音频播放与结束处理，以及旧版记录的存储和补传兼容性。网页类型检查、构建和 ESP-IDF 固件编译分别验证对应软件产物；它们不证明实板断电保存、小智账号绑定、联网对话成功或语音听感。实际通过的检查以本次执行结果为准，不沿用旧固件的测试数量作为新功能验收。

以下项目必须由实板确认，不能用编译或自动化测试代替：

1. 灯 1～5 的实体顺序、1% 最低亮度和统一慢闪节奏。
2. S1 连续回听更早语音、S2 重设回听起点、播放中一次按键切换的行为，以及 S3 旋钮方向。
3. S2 完整播放后的已读回执与中断播放不标已读。
4. S5 首次短按录音、再次短按发送、录音中/满 20 秒后长按取消、快速连续两次短按、Flash 缓存和发送成功提示；旧记账待同步记录及 CSV 导出仍可用。
5. 每日闹钟跨重启保存、NTP 时间同步和到点提示。
6. 倒计时每秒滴答、每分钟长滴答与剩余分钟播报。
7. 网页直接开关实时麦克风、声音延迟、断续、底噪，以及监听时操作 S7/S8 的声音效果。
8. S6 首次绑定、开始对话、小智回答播放、尾音结束后恢复收音、多轮交谈、旋钮调音量，以及连接中、收音中、回答中再次短按立即结束。检查断网失败提示、快速启停、与网页监听或普通录音的互斥，且对话内容不进入时间线。
9. S7 妈妈优先的四项循环、S8 爸爸/妈妈切换、旋钮方向与粗细步进、第一次短按进入精调、第二次短按保存、静置不保存、3 秒取消及重新上电后的最近值播报。
10. 共享 GPIO8 电源、麦克风声道、扬声器音量以及录音回放音质。

### 容量说明

5000 条均录满 20 秒时，云端原始压缩音频约 800 MB，另加数据库与索引开销；下载的 WAV 总计约 1.6 GB，分包保存。实际可用空间和请求额度以 Cloudflare 账户套餐、用量为准，达到平台额度可能导致上传失败。建议保留需要的本地 ZIP 备份。实时监听仍不保存音频。扩容不改变开发板离线 8 条录音、64 条待同步测量记录的容量。
